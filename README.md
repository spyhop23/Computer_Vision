# Computer Vision Mini Labs

This repository contains mini labs for computer vision fundamentals:
image filtering & resampling, panorama stitching, and transfer learning for object detection.

## Contents
- **Resampling with Gaussian filtering**
  - Downscale/upscale with Gaussian kernels to reduce aliasing
- **Panorama stitching**
  - Keypoint detection/matching, homography estimation, warping, blending
- **Balloon detection (bounding boxes)**
  - Fine-tune a pretrained detector on the balloon dataset and visualize predictions
